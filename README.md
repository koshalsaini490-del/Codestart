# CodeStart — GitHub Pages version

This is a static website. No React, build step, or API key is required.

## Publish from your phone
1. Extract this ZIP on your phone.
2. Sign in at https://github.com and tap **+** → **New repository**.
3. Name it `codestart`, select **Public**, and create it.
4. Tap **Add file** → **Upload files** and upload `index.html`. Commit the changes.
5. Open **Settings** → **Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then tap **Save**.
7. Wait a few minutes. GitHub Pages will show your website URL in Pages settings.

To use the address `yourusername.github.io`, name the repository exactly `yourusername.github.io`. Otherwise, the URL usually ends with `/codestart/`.

The quiz and lesson progress run in your browser. Progress is stored locally on this device/browser.
